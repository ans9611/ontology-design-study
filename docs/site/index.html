How to read it

A pattern seen only in sustained systems is an association, not a cause: eight purposive cases, no controls. Patterns observed in the two non-sustained cases (Freebase: abandoned; Cyc: limited adoption) are the ones to treat as risk signals when they appear in a new design. Grade B/C sources are practice evidence, not effect evidence.
