Which patterns go with systems that lasted

A pattern seen only in sustained systems is an association, not a cause: eight purposive cases and no controls. Patterns from the two non-sustained cases, Freebase (abandoned) and Cyc (limited adoption), are the ones to treat as risk signals when they show up in a new design.
