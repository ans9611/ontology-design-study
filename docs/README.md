# docs/

Every document of the study, with what it is for and when to read it. The site in `site/` is generated from these; nothing on it is typed by hand.

## Read in this order

| step | file | what it is |
|---|---|---|
| 1 | [`guidelines.md`](guidelines.md) | the twelve practitioner guidelines, each tied to its evidence and strength; the shortest complete statement of what the study supports |
| 2 | [`results/RESULTS.md`](results/RESULTS.md) | RQ3 results: setup, headline numbers, per-query table, hypothesis verdicts, four follow-up runs; tables generated from the CSVs beside it |
| 3 | [`hypotheses.md`](hypotheses.md) | the four hypotheses as registered before the run, with dated notes on every deviation |
| 4 | [`cases/README.md`](cases/README.md) | the eight cases and the pattern-by-case matrix; one file per case, [`CODEBOOK.md`](cases/CODEBOOK.md) for a second coder |
| 5 | [`metrics-matrix.md`](metrics-matrix.md) | RQ1: seven quality frameworks against six property groups |
| 6 | [`schema-review.md`](schema-review.md) | the three RQ3 schemas checked against Neo4j's modeling checklist |
| 7 | [`protocol.md`](protocol.md), [`search-log.csv`](search-log.csv), [`slr/`](slr/) | the review protocol, every search run dated, and the candidate lists with screening decisions |

## By strand

| strand | question | files |
|---|---|---|
| RQ1, literature review | what do quality metrics measure and omit | `protocol.md`, `search-log.csv`, `slr/`, `metrics-matrix.md` |
| RQ2, case study | which patterns recur in sustained and abandoned graphs | `cases/` |
| RQ3, experiment | how hops, latency and memory scale under three schemas | `hypotheses.md`, `results/`, `schema-review.md` |
| synthesis | what a practitioner should do | `guidelines.md` |

## Files in `results/`

| file | content |
|---|---|
| `bench.csv`, `sizes.csv` | main run: per (scale, schema, query) hops, scans, property reads, best-of-five seconds and every repeat; per (scale, schema) build time, node and edge counts, resident MB |
| `bench_indexed.csv`, `sizes_indexed.csv` | flat with reverse indexes |
| `bench_skew.csv`, `sizes_skew.csv` | Zipf fan-in |
| `bench_kuzu.csv`, `sizes_kuzu.csv` | six diagnostic queries on Kùzu |
| `writes.csv` | records touched and time per update |
| `fig1_hops`, `fig2_scaling`, `fig3_memory`, `fig4_followups` | figures, PNG and PDF, regenerated by `python -m ontostudy.figures` |

## Regenerating

```bash
python -m ontostudy.report    # tables in results/RESULTS.md
python -m ontostudy.figures   # results/fig*.png and .pdf
python -m ontostudy.site      # site/data.json
```
